routers and abstraction layers
you put a separate component (third party) in between you and the providers like your bridge
a router is a remote process you connect out to and it routes on your request to 1 of the other providers
an abstraction layer is when you have a framework, some code running on your computer and you call the code with consistent api and it then desides how to call each of the providers separately

router example
    response = openrouter.chat.completions.create(model="z-ai/glm-4.5", messages=tell_a_joke) // check the modals on the website
    display(Markdown(response.choices[0].message.content))

    from litellm import completion
